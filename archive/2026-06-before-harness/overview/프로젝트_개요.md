# 프로젝트 개요

## 서비스명

Allreva

## 한 줄 소개

공연 관람객이 차량 대절을 모집하고 참여할 수 있도록 돕는 팬덤 활동 지원 서비스입니다.

## 문제 인식

콘서트나 팬 행사에 참여할 때 필요한 차량 대절 정보는 주로 X(트위터), 오픈채팅, 개인 폼 등 여러 채널에 흩어져 있습니다. 이 때문에 사용자는 모집 글을 직접 찾아야 하고, 주최자는 신청 인원과 마감 여부를 별도로 관리해야 합니다.

기존 팬덤 플랫폼은 특정 기획사나 공식 활동 중심으로 구성된 경우가 많아, 팬들이 직접 조직하는 차량 대절이나 비공식 행사 관리를 충분히 지원하지 못합니다.

Allreva는 이런 분산된 팬 활동 정보를 한곳에서 정리하고, 차량 대절 모집부터 신청 관리까지 일관된 흐름으로 제공하는 것을 목표로 했습니다.

## 주요 기능

### 1. 차량 대절 모집 및 신청

- 공연별 차량 대절 모집 생성
- 날짜/탑승지별 신청 관리
- 정원 초과 방지
- 참여 내역 조회

### 2. 공연 정보 조회

- 공연 정보 목록 및 상세 조회
- 지역/검색어 기반 공연 검색
- KOPIS 기반 공연 데이터 동기화

### 3. 공연장 정보 조회

- 공연장 상세 정보 조회
- 공연장 기반 관련 공연 조회

### 4. 알림

- 신청 상태 변경 알림
- 일정 리마인더
- 비동기 알림 전송 구조 검토

## 타겟 사용자

- 공연 관람과 팬덤 활동에 적극적으로 참여하는 사용자
- 차량 대절을 직접 모집하거나 참여하려는 사용자
- 여러 SNS에 흩어진 팬 활동 정보를 한곳에서 확인하고 싶은 사용자

## 기술 스택

- Java 17
- Spring Boot 3.x
- Spring Web MVC
- JPA, QueryDSL
- PostgreSQL 16
- Redis
- Firebase
- Docker
- GitHub Actions
- Nginx

## 문서화 방향

이 저장소는 단순 사용 설명서가 아니라, 프로젝트를 만들며 내린 설계 판단과 문제 해결 과정을 남기기 위한 문서 저장소입니다.
