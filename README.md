# Allreva Docs

Allreva를 만들면서 남긴 설계 판단, 문제 해결 과정, 실험 결과를 모아 둔 저장소입니다.

Allreva는 공연 팬들이 공연 정보를 찾고, 차대절 모집과 수요조사에 참여할 수 있도록 돕는 서비스입니다. 백엔드와 프론트엔드 코드는 별도 저장소에서 관리합니다.

이 저장소에는 다음 내용을 기록합니다.

- 서비스와 도메인을 이해하는 데 필요한 설명
- 시스템 구조와 중요한 설계 결정
- 테스트, 배포, 운영에서 확인한 기준
- 동시성, 성능, 장애를 분석하고 해결한 과정

문서는 사람이 읽기 쉽게 쓰는 것을 우선합니다. 현재 구조와 맞지 않을 수 있는 예전 자료는 보존하되, 현재 기준 문서와 분리해서 관리합니다.

개발 과정에서 문서를 찾거나 갱신해야 한다면 [INDEX.md](INDEX.md)부터 확인하면 됩니다.
