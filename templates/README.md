# 문서 템플릿

여기에는 반복해서 사용하는 문서의 기준 양식을 둔다. 템플릿은 빠짐없이 채우는 서식이 아니라, 읽는 사람이 필요한 정보를 빠르게 찾도록 돕는 도구다.

- [기능 Issue](feature-issue.md): 목표, 범위, 완료 조건이 필요한 변경
- [버그 Issue](bug-issue.md): 재현 조건과 실제 결과를 남겨야 하는 오류
- [공통 작업 Issue](work-issue.md): 리팩터링, 테스트, 문서, CI/CD, 운영 정리
- [PR](pull-request.md): 변경 이유, 검증 결과, 공식 문서 연결
- [RFC](rfc.md): 경계가 바뀌는 변경의 선택지와 권장안
- [ADR](adr.md): 확정된 결정, 이유, 감수한 점, 영향
- 실험의 가설, 재현 조건, 측정값, 한계는 관련 RFC의 `검증 결과`에 기록한다.

Issue 템플릿은 실제 GitHub Form에도 같은 구조로 반영한다. 다만 GitHub Form의 설명은 더 짧게 쓰고, 이 문서는 각 항목을 왜 쓰는지 설명하는 기준으로 사용한다.
