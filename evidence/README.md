# 실험과 검증 근거

이 폴더에는 성능 측정, 장애 재현, 동시성 검증처럼 결과를 직접 확인한 기록을 둔다.

각 실험은 문서와 원본 자료를 함께 남긴다. 문서에는 가설, 재현 조건, 측정값, 해석, 한계를 적는다. 스크립트, 설정, 원본 결과, 스크린샷은 실험 문서가 가리키는 같은 폴더에 둔다.

```text
evidence/
└── YYYY-MM-DD-실험-이름/
    ├── README.md
    ├── scripts/
    ├── results/
    └── images/
```

민감정보는 저장하지 않는다. API key, 토큰, 쿠키, 개인정보, 운영 서버 주소는 제거하거나 안전한 예시 값으로 바꾼다.
